# Поиск автозапчастей «Фаворит»

Тестовое задание: клиентское React-приложение для двухэтапного поиска автозапчастей через API «Фаворит».

## Возможности

- поиск производителей по артикулу;
- загрузка аналогов и аналогов после выбора производителя;
- отображение названия, производителя, остатка и цены;
- состояния загрузки, ошибок и пустых результатов;
- адаптивный интерфейс.

## Стек

React, Redux Toolkit, Bootstrap, Vite и Fetch API.

## Запуск

```bash
npm install
npm run dev
```

Для проверки можно использовать артикул `7160500039S` из документации.
